# Expeditions: the postings on the board, and the events crew meet on them.
#
# posting <sector> <danger 1-3> <the posting's words>
#
# event <id> <sector>[,<sector>...]       (any = every common sector; a homeworld also meets its race's events)
# <the event's words, as many lines as needed>
# * <a choice anyone can take>
# * [<race>] <a choice open with that race in the party: blue>
# * [red <race>] <a choice that race brings, and makes worse: red>
#   ok <effects> | <words>                 a sure outcome, or:
#   roll <chance of the first, in %>
#   win <effects> | <words>
#   lose <effects> | <words>
#
# Effects: scrap 5-10, injure 1, lose 1, fuel 2, missiles 1, parts 1, item weapon|drone|augment, end (the expedition
# turns for home). In the words: {who} is the crew member the choice is about (the race's, else someone in the party),
# {crew} anyone in the party, {sector} the sector's name.
# Races: human, engi, mantis, rock, slug, zoltan, crystal, lanius. Sectors: civilian, engi, zoltan, mantis, rock, slug,
# nebula, pirate, rebel, abandoned; rare: engi_home, mantis_home, rock_home, zoltan_home, slug_home, crystal.
# Every event needs at least two ways through without a race. Write fresh: FTL's tone, never FTL's text.
# Voice: "the rebels" lowercase; the Rebel Flagship is never said to be destroyed.
